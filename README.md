# Data Engineer Portfolio

A modern, responsive portfolio website showcasing my experience and skills as a Data Engineer.

## Features

- Responsive design with mobile-first approach
- Dark/Light theme toggle
- Modern glassmorphism UI
- Interactive timeline for experience
- Animated sections and transitions
- Contact form
- SEO optimized
- PWA ready

## Technologies Used

- HTML5
- CSS3 (with modern features)
- JavaScript (Vanilla)
- Bootstrap 5
- Font Awesome
- Google Fonts

## Setup and Development

1. Clone the repository:
   ```bash
   git clone https://github.com/azim2429/azim2429.github.io.git
   ```

2. Navigate to the project directory:
   ```bash
   cd azim2429.github.io
   ```

3. Open index.html in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   # Using Node.js
   npx serve
   ```

## Deployment

This site is configured to deploy on GitHub Pages. To deploy:

1. Push your changes to the main branch
2. GitHub Actions will automatically build and deploy to GitHub Pages
3. Your site will be available at https://azim2429.github.io

## Customization

1. Update personal information in `index.html`
2. Modify styles in `styles/main.css`
3. Update theme colors in the `:root` CSS variables
4. Add/modify sections as needed
